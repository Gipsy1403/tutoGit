# Documentation du tuto GitHub 

## Initialisation du dépôt
```bash
git init
git remote add origin HTTPS ou SSH du repo
git add .
git commit -m"initial commit"
git push origin main
```

## Ajouter votre identité si clonage d'un repo
```bash
git config --global user.name "Gipsy1403"
git config --global user.mail "r...@...fr"
```
## Voir historique
```bash
git log : connaitre tout l'historique de l'application
git show : connaitre en détail tout l'historique

```
